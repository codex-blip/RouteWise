Ride-hailing MVP

RouteWise

A full-stack, real-time ride-hailing platform — FastAPI backend, Next.js frontend, Mapbox maps, Stripe payments, and WebSocket-driven live tracking.

FastAPI Next.js Mapbox GL Stripe WebSockets PostgreSQL

Core capabilities

Dual-role users

Separate rider and driver accounts with role-based flows, all persisted via async SQLAlchemy on PostgreSQL.

Interactive maps

Live Mapbox GL rendering with dynamic markers for pickup, dropoff, and active vehicles updating in real time.

Pre-auth payments

Stripe Elements authorize fare at request time; capture fires only on successful trip completion.

Real-time WebSockets

Bidirectional streams push driver GPS positions and trip phase changes from server to client instantly.

OTP trip security

One-time passcode verification before trip start prevents unauthorized driver spoofing.

Async DB engine

Full asyncpg + SQLAlchemy Async stack with Alembic migration history for zero-downtime schema changes.

Getting started

Backend
Frontend
Env variables
1

Enter the backend

Navigate to the backend directory and set up your Python environment.

cd backend
python -m venv venv
# macOS/Linux
source venv/bin/activate
# Windows
.\venv\Scripts\activate
2

Install dependencies

Uses Poetry metadata via requirements.txt for a clean install.

pip install -r requirements.txt
3

Run migrations & start

Apply Alembic schema history, then start the dev server with hot-reload.

alembic upgrade head
uvicorn app.main:app --reload
1

Enter the frontend

Navigate and install Node packages for the Next.js app.

cd frontend
npm install
2

Add .env.local

Create your local env file (see the Env variables tab for keys).

3

Start dev server

Runs on localhost:3000 by default with fast refresh.

npm run dev
